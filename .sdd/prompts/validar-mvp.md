# Prompt reutilizable: Validar el MVP

Analiza el checkout de SDLC Manager usando `.sdd/config.yaml` y la spec activa.

1. Verifica que `requirements.md`, `design.md` y `tasks.md` estén alineados.
2. Revisa que las tareas completadas tengan evidencia en código, pruebas o documentación.
3. Ejecuta los comandos de calidad definidos en `AGENTS.md`.
4. Comprueba que las políticas no usen ejecución dinámica y que las evidencias verifiquen su estado.
5. Reporta hallazgos con ruta, requisito afectado, severidad y corrección propuesta.

No modifiques archivos durante una auditoría salvo que exista una tarea explícita para corregir el hallazgo.
