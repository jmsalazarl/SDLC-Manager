# SDLC Manager

Consulta las herramientas MCP cuando una tarea modifique componentes relevantes,
inicie una HU o requiera evaluar un gate. Presenta las experiencias aplicables
sin inventar aprobaciones. `WARN` informa y `BLOCK` solo se aplica mediante un
mecanismo de enforcement autorizado.
